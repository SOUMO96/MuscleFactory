# Muscle Factory

A cross-platform gym & workout tracking app built with Flutter, with Firebase
for authentication and data storage.

## Status

The UI is fully built out — a cohesive dark, high-energy theme across
onboarding, auth, home dashboard, workout library/detail, progress, and
profile. Workout/exercise content is still static placeholder data, but
**authentication and user profiles are real**:

- Email/password sign up & login via Firebase Auth
- Google Sign-In (redirect-based, so it works inside embedded browser
  panels/webviews as well as real browser windows)
- User profile documents stored in Cloud Firestore at `users/{uid}`
- Firestore security rules restrict each user to their own document

## Structure

```
lib/
  core/
    theme/          # colors, text styles, ThemeData
    widgets/         # reusable UI building blocks (buttons, cards, headers)
    navigation/      # bottom-nav shell (MainShell)
    services/        # AuthService, UserRepository (Firebase wrappers)
  features/
    splash/          # boot screen; resolves auth state before routing
    onboarding/       # 3-page swipeable intro
    auth/             # login / sign up (wired to Firebase Auth)
    home/             # dashboard (today's stats, featured workout, recs)
    workouts/         # workout library + detail screen
    progress/         # charts, stats grid, achievements
    profile/          # profile + settings menu, real signed-in user + logout
  shared/
    models/           # plain data models (Workout, ExerciseItem, AppUser)
    data/             # static dummy workout/exercise data
  firebase_options.dart   # generated by `flutterfire configure`
main.dart
```

## Getting started

```bash
flutter pub get
flutter run -d chrome     # or -d web-server if -d chrome is blocked locally
```

Firebase project: `fitnessfactory-946fc`. If you need to reconfigure or add a
platform, run `flutterfire configure` from the project root.

## Design language

- Deep near-black backgrounds with elevated card surfaces
- Neon lime (`#CCFF00`) as the primary energy accent, orange as secondary
- Bold, condensed headings (Manrope) for a gym/athletic feel
- Rounded 16–20px corners, soft glow shadows on primary actions
- Bottom nav with a center "quick start" floating action button
